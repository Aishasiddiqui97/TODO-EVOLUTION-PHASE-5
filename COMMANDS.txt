================================================================================
WEBSOCKET BACKEND - RUN COMMANDS
================================================================================

METHOD 1: BATCH FILE (EASIEST)
-------------------------------
start-websocket-fixed.bat


METHOD 2: MANUAL COMMAND
-------------------------
cd backend\src
python -m uvicorn services.websocket_sync.main:app --host 0.0.0.0 --port 8004 --reload


METHOD 3: POWERSHELL
--------------------
.\start-websocket.ps1


================================================================================
VERIFICATION COMMANDS
================================================================================

Check if service is running:
curl http://localhost:8004

Check service stats:
curl http://localhost:8004/stats

Check what's using port 8004:
netstat -ano | findstr :8004

================================================================================
TROUBLESHOOTING
================================================================================

If "ModuleNotFoundError":
cd backend\src\services\websocket_sync
pip install -r requirements.txt

If "Address already in use":
netstat -ano | findstr :8004
taskkill /PID <PID> /F

If service won't start:
Check you're in the right directory (backend\src)
Check Python is installed: python --version
Check dependencies: pip list | findstr fastapi
