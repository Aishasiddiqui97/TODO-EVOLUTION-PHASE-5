## 🏗️ Architecture

### Microservices (5)
1. **Chat API** (8001) - Natural language interface with OpenAI
2. **Recurring Task Service** (8002) - Automatic task recurrence
3. **Notification Service** (8003) - In-app and email notifications
4. **WebSocket Sync Service** (8004) - Real-time synchronization
5. **Audit Log Service** (8005) - Immutable audit trail

### MCP Tools (7)
- `create_task` - Create tasks with natural language
- `update_task` - Update task properties
- `complete_task` - Mark tasks complete (triggers recurrence)
- `delete_task` - Delete tasks
- `list_tasks` - List with advanced filtering
- `search_tasks` - Natural language search
- `get_preferences` / `update_preferences` - User settings

### Infrastructure
- **Dapr:** PubSub (Redis), State Store (Redis), Secrets API
- **Kubernetes:** Deployments with Dapr sidecars
- **Observability:** Prometheus metrics, Zipkin tracing
- **CI/CD:** GitHub Actions (lint, test, build, deploy)
